# mymuduo - 高性能 C++ 网络库

基于 Reactor 模型与 epoll 实现的高性能多线程 C++ 网络库，支持高并发连接处理与低延迟通信。项目对经典 Muduo 架构进行重构，并在多核环境下进行了系统级性能优化。

---

## 🚀 核心能力

- 基于 **Reactor + epoll** 的高并发事件驱动模型
- 实现 **One Loop Per Thread** 多线程架构，充分利用多核资源
- 支持 **10k+ 并发连接稳定运行**
- 自研 **双缓冲异步日志系统**，降低高频 IO 开销
- 基于 **时间轮 + weak_ptr** 实现连接生命周期管理与心跳检测

---

## 🧱 架构设计

系统采用分层解耦设计：

- **EventLoop**：事件循环与调度核心
- **Channel**：事件分发与回调管理
- **TcpConnection**：连接生命周期管理
- **Buffer**：高效数据读写缓冲区
- **ThreadPool**：多线程事件处理

主线程负责连接接入，子线程负责 I/O 处理，实现高并发下的负载均衡。

---

## 📊 性能表现

在 14 核 Linux 环境下使用 wrk 进行压测：

- **并发连接数**：500+
- **QPS**：128,000+
- **平均延迟**：≈ 460μs
- **99% 延迟**：≈ 1.15ms
- **稳定性**：无连接错误（无 read/write/socket error）

---

## 🔧 关键优化

### 1. 高并发日志优化
通过编译期宏剥离日志调用，消除高频场景下 IO 对性能的影响，使系统算力聚焦于网络处理。

### 2. 连接生命周期管理
利用 `weak_ptr` 解决循环引用问题，避免连接无法释放导致的资源泄漏。

### 3. Reactor 调度优化
优化事件分发与 epoll 调用路径，在高并发场景下显著提升吞吐能力。
